mulle.js demo

Det här är en lokal demosida som följer med bygget. Den visar att distributionen, datafilerna och den statiska servern fungerar även om de ursprungliga ljud- och bildresurserna inte finns incheckade i repot.

Så provar du

  • Kör npm install första gången.
  • Kör npm run demo och öppna adressen som skrivs ut.
  • Spelet kör offline som standard. Lägg till ?multiplayer=1 för att ansluta till websocket-servern.
  • Full spelupplevelse kräver exporterade assets/*.json, atlasbilder, ljud och ui/-pekare från originalresurserna.
